## 它是什么

Bromeme 把中文互联网的 meme 文化做进了 Brotato：一套 **meme 值** 成长系统、随机 **meme 入侵**（会出现专属首领）、波末 **4 选 1 卡牌**（融合/改造/转职/随机抽取/专属道具）、以及若干原创角色与宠物。

模组 ID 前缀统一为 `bromeme`（`item_bromeme_*` / `character_bromeme_*`）。

## 安装

1. 订阅 Steam 创意工坊版本，或手动安装：
2. 把 `Bromeme.zip` 放进 Brotato 的 mods 目录，让 ModLoader 能扫到它：

```
%APPDATA%\Brotato\mods\Bromeme.zip
```

3. 启动游戏，在 **Mods** 菜单中确认 `bromeme` 已启用。
4. 日志（`%APPDATA%\Brotato\logs\godot.log`）里应能看到注册自检：

```
已注册 21 个角色 / 97 个物品
```

> ⚠️ **存档兼容性**：2.32.0 做过一次全量 ID 改名（`item_brolab_*` → `item_bromeme_*`）。若你从非常老的版本升级，建议**开新档**，旧存档里的老道具无法识别。

## 主要内容

### Meme 系统

- **meme 值**（`stat_meme`）是一个自定义属性，通过购买专属道具、事件奖励等途径累积。
- 每波开始按概率触发 **meme 入侵**：`y = 1 - exp(-(max(x,0)/100)^0.9)`，meme 值越高越频繁（1 点约 1.6%，100 点约 63.2%）。
- 入侵发生时播放专属音效（汽笛 / 罐头笑声 / 礼炮 / 鼓掌，全部代码合成，无音频文件）并有概率叠加第二层音效。
- 入侵会把本波首领替换成 **meme 首领**。

### 波末 4 选 1 卡牌

每波结束（进入商店前）弹出专属面板，4 张卡 + 重掷/跳过。重掷消耗金币：`(5 + 10*波数) * (1 + 波数*0.1)`，同一面板内每次重掷 ×1.25。

| 卡类型 | 概率 | 效果来源 | 说明 |
|---|---|---|---|
| **融合组合卡** `mix` | 兜底 | 2 件道具的**全部**效果 | 名字取前一件开头一半 + 后一件结尾一半 |
| **改造组合卡** `comboswap` | ≈20% | 2 件道具全部效果 + 随机换 1~2 条属性 | 名字尾部带 `？` |
| **改造卡** `swap` | ≈10% | 1 件道具全部效果 + 随机换 1~2 条属性 | 数值浮动 -25%~+200% |
| **随机抽取卡** `draw` | ≈20% | **3~4 件道具各取一条效果** | 名字 = 每件各取一个词根 |
| **转职卡** `job` | 15% | 一条主属性 → 另一条 | 按加点表推算价值比 |
| **专属道具卡** `exclusive` | 10% | 单件专属道具 | meme 核心/混沌/随机/出售/熵/赌徒/量子/献祭/蝾螈/苍/赫 |
| **混沌卡** | 5% | 更混沌的一批道具 | 每轮最多一张 |
| **角色卡** `character` | 5% | 随机一个本 mod 角色 | 获得该角色的全部效果 |

被选中的卡会**变成一个真实道具**进入背包（带 Bromeme 水印图标），道具的图标与名称会随存档持久化。

### Meme 首领

| 首领 | 特点 |
|---|---|
| **魂5** (`hun5`) | 镰刀/剑近战（带前摇）、弹幕群、激光、红色弩箭；二阶段后撤 + 随机游走；攻击后 30% 概率无后摇接招 |
| **万** (`van`) | 三连冲刺（短→短→长）+ 冷却期扇形弹幕与「♂」字弹幕 |
| **王源** (`wangyuan`) | 多列香烟弹幕、烟雾分身 |
| **孙笑川** (`sunxiaochuan`) | 字母弹幕（每个字母一种弹幕形态）；二阶段弹幕与冲刺交替 |
| **叛忍** (`panren`) | 瞬移绕后 + 尖刺路径、手里剑、冲刺连段 |

所有首领出手前都会播放原版 `shoot` 动画作为**前摇**（1 秒动画，0.8 秒处由动画 method 轨回调真正出招），与 BossRush / 原版首领的节奏一致。

### 苍与赫

挑战者初始携带的两个环绕宠物（模仿原版流浪机器人，但半径更大：240 vs 100~200）：

- **苍**：对怪物与子弹有**吸引力**，对触碰到的怪物持续造成伤害
- **赫**：对怪物与子弹有**排斥力**，对触碰到的怪物持续造成伤害

伤害公式：`5 + 200%等级 + 50% meme 值 + 50% 近战伤害 + 50% 元素伤害`，苍的伤害减半。两者都是 `max_nb = 1`（各最多持有 1 个），不进商店，只从 meme 奖励池产出。

### 挑战者

- 使用 AI 绘制的全新立绘（局内身体贴图与菜单图标分开维护）
- 每击杀一个精英或首领：**+5 生命再生、+5% 伤害**
- 靠近自身的怪物会减速（距离 150 开始，越近越慢）
- 每波必定触发 meme 入侵

```

│   ├── manifest.json                  # 清单（含完整更新日志）

│   ├── brolab_compat/                 # BroLab 内容兼容层

│   ├── aiart_src/                     # AI 绘图源文件与参考图

│   └── image/                         # 立绘源图

```

## 从源码构建

需要 **Python 3**。构建脚本会**重新生成** `art/char`、`art/item`、`art/body` 三个目录：

```bash
python tools/bromeme_build.py
```

产出 `D:\DSH\Bromeme\Bromeme.zip`（脚本内路径按本机工程布局硬编码，换机器请改 `bromeme_build.py` 顶部的路径常量）。

**美术来源优先级**（`_icons_for()`）：

```
resources/edited/<stem>.png  >  resources/edited/<stem>.body.png  >  resources/icons/<icon-rel>
```

> 注意：产物文件名按 **json 文件名主干**命名（例如 `1791000301.json` → `art/item/1791000301.png`），而不是按 `relative_icon_path`。`resources/icons/` 不会被打进 zip。

## 开发工具

`tools/` 下是与本机 Brotato 安装配套的离线工具，核心几个：

| 工具 | 用途 |
|---|---|
| `bromeme_build.py` | 打包：生成 `art/` 并产出 `Bromeme.zip` |
| `mk_bromeme_checks.py` | 生成 GDScript 解析检查工程 |
| `source_health_check.py` | 源码健康检查 |
| `*check/` | 各脚本的独立 Godot 解析检查工程（`enemycheck` 覆盖 5 个首领） |

这些检查工具的价值在于：**脚本扩展一旦解析失败，ModLoader 会静默地把扩展装到 `Null` 上**（日志里表现为 `Installing script extension: Null <- ...`），游戏照样能跑但功能全丢。用独立工程做解析检查可以在启动游戏前就抓到这类问题。

## 兼容性

- 游戏版本：`1.1.15.4`（自定义 Godot 3.7.dev 构建）
- ModLoader：`6.2.2`
- 已知冲突：`FengLiu-FengAddMods`（该 mod 会拦截 The-BossRush 对 `res://items/global/item_parent_data.gd` 的扩展，导致 160+ 原版脚本解析失败）。Bromeme 会在自身 `_init` 阶段检测并尝试重新安装被拦截的扩展，但两者同时启用仍不稳定。
